=============Contract: AurumNodePool
Sink:
Reasoning:
- `constructor` only runs at deployment and is not callable by arbitrary users, so it is not a sink.
- `createNode` is an intended user purchase path. It uses `transferFrom(account, address(this), price)` with `account = msg.sender` and sends the fee to `teamWallet` as part of contract logic. It does not modify another user’s assets without authorization.
- `claimNodeReward` and `claimAllNodesReward` read and update only `_nodesOfUser[msg.sender]` and transfer rewards to `msg.sender`. These are intended claim operations and are not access-control sinks.
- `setTeamWallet`, `setTeamFees`, and `setMaxNodes` are protected by `onlyOwner`, so they are not sinks.
- `changeNodePrice` and `changeRewardPerNode` have no access-control modifier and write critical configuration state variables.
